About this project

Heart Disease Prediction

This Django application uses a trained machine learning model to predict the likelihood of heart disease based on clinical input values such as age, blood pressure, cholesterol and ECG results. The model was trained on the standard heart disease dataset and is served through a scikit-learn pipeline.

Try the prediction

Technology

Django for the web application, scikit-learn for the trained pipeline, and pandas for preparing the input data.

Inputs

Eleven clinical values including age, sex, chest pain type, resting blood pressure, cholesterol and ST slope.

Disclaimer

Built as a college machine learning project. Results are for educational purposes and are not a medical diagnosis.
